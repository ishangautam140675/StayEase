7. Top Viva Questions & Winning Academic Answers

Q1 StayEase race conditions aur double-booking ko kaise prevent karta hai?
"Sir, hum database-level PESSIMISTIC_WRITE row locking (SELECT ... FOR UPDATE) use karte hain inside a @Transactional boundary. Jab User A book karta hai, us room ki row lock ho jaati hai. Agar User B concurrently try karega, uska transaction wait karega aur interval check fail ho jayega: (existing.checkIn < new.checkOut) AND (existing.checkOut > new.checkIn)."
Q2 Google Maps API ke badle OpenStreetMap kyun use kiya?
"Google Maps mandatory credit card billing maangta hai aur per request heavy charge karta hai. OpenStreetMap (Overpass & Nominatim) paired with Komoot Photon 100% free hai, open-source hai, worldwide coverage deta hai, aur raw geospatial tags ko bina kisi billing risk ke access karne deta hai."
Q3 Spring, Spring Boot, aur Spring Data JPA mein kya difference hai?
"Spring underlying IoC container hai jisme manual XML/Java configuration karni padti thi. Spring Boot auto-configuration aur embedded Tomcat server deta hai standalone running ke liye. Spring Data JPA Hibernate par based data persistence layer hai jo Java Entities ko bina raw SQL ke database se map karti hai."
Q4 Typeahead search box browser ya server ko lag kyun nahi karta?
"Humne client-side debouncing (220-millisecond delay) lagaya hai. Har keystroke par request nahi jaati; jab user 220ms ka pause leta hai tabhi single HTTP call jaati hai. Saath hi client memory cache aur backend ConcurrentHashMap caching repeated queries ko instant return karti hain."
Q5 Passwords database mein kaise securely store hote hain?
"Passwords kabhi plaintext mein store nahi hote. Hum Spring Security ka BCryptPasswordEncoder use karte hain. Yeh adaptive one-way hashing function har password ke sath ek unique random salt jodta hai, jisse do same passwords ke bhi database hashes bilkul alag aate hain (rainbow table attack immune)."
Q6 User aur hotel ke beech ka distance kaise calculate hota hai?
"Humne Java mein Haversine Formula implement kiya hai (calculateDistanceKm(lat1, lon1, lat2, lon2)). Earth round (spherical) hai, isliye normal 2D Pythagoras theorem coordinates par fail ho jata hai. Haversine spherical trigonometry se do GPS points ka exact great-circle surface distance kilometers mein nikalta hai."
Q7 Admin Dashboard mein ADR aur RevPAR ka kya matlab hai?
"ADR (Average Daily Rate): Booked rooms se per day average revenue: ADR = Total Room Revenue / Rooms Sold. RevPAR (Revenue Per Available Room): Pure property ke saare available rooms ka per-room performance: RevPAR = ADR × Occupancy Rate."
Q8 CSRF kya hai aur StayEase isse kaise protect karta hai?
"CSRF (Cross-Site Request Forgery) ek exploit hai jisme unauthorized website authenticated session se unauthorized commands bhejti hai. StayEase Spring Security ka synchronizer token pattern use karta hai: har state-changing POST form ke sath secret _csrf token verify hota hai."
Q9 Kaise prove karoge ki system bug-free aur production-ready hai?
"Humne JUnit 5, Mockito aur MockMvc use karke 295+ Automated Tests likhe hain jo login security, role authorization, concurrency race conditions, date overlap aur API endpoints ko verify karte hain with 100% pass rate."
